# 🎓 Student Performance Analysis Dashboard

## 📌 Overview
This project is an interactive Power BI dashboard that analyzes student academic performance using KPIs, charts, and interactive filters.

## 🚀 Features
- Student Count KPI
- Average Math Score
- Average Reading Score
- Average Writing Score
- Score Percentage by Ethnicity
- Score Percentage by Gender
- Score Percentage by Parental Education
- Score Percentage by Test Preparation
- Top 5 Students by Performance
- Interactive slicers for:
  - Ethnicity
  - Gender
  - Parental Education
  - Test Preparation
  - Student ID

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## 📂 Dataset
The dataset contains:
- Student ID
- Gender
- Ethnicity
- Math Score
- Reading Score
- Writing Score
- Parental Education
- Test Preparation
